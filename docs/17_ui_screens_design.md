## ۲. قواعد عمومی

- یک کار اصلی در هر صفحه؛ دکمه‌ها بزرگ برای انگشت (اندازه بر اساس اینچ، موجود).
- راست‌به‌چپ؛ ستون اصلی سمت راست.
- ابزار فوری در HUD با لمس مستقیم (بدون منو).
- همهٔ خریدها با سد ساده‌ٔ تأیید.
- هیچ چت آزاد؛ استیکر/پیام آماده فقط در بخش آنلاین.
- هر صفحه یک تست اسکرین‌شات دارد (`tools/screenshot.tscn`).

## ۳. چرخهٔ طراحی-ساخت

1. صاحب پروژه طرح صفحه را می‌دهد.
2. Claude Code **عین طرح** می‌سازد و از آن اسکرین‌شات می‌گیرد.
3. کنار طرح مقایسه؛ اگر تضاد فنی بود: نزدیک‌ترین نسخهٔ وفادار + گزارش + سؤال.
4. تأیید ← کامیت ← ستون «طرح» این جدول به‌روز می‌شود.
