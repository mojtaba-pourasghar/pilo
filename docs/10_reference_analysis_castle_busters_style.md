# تحلیل سبک مرجع: رابط براق و شیشه‌ای (الهام، نه کپی)

> صاحب پروژه یک اسکرین‌شات از رابط «ساختمان‌شکن‌ها» (Castle Busters) داد تا **حس و کیفیت** مشخص شود. این سند فقط اصول را به‌صورت متن ثبت می‌کند. **هیچ تصویر، شکل یا عنصر عین‌به‌عین کپی نمی‌شود** و تصویر مرجع به مدل تصویر داده نمی‌شود.

## ۱. مشاهده (متنی)

1. **رنگ:** پس‌زمینه‌های بسیار روشن و اشباع، آسمان‌های رنگی، سایه‌های ملایم؛ حس «شادی و جایزه».
2. **دکمه‌ها:** بزرگ، گرد، شیشه‌ای و براق، با لبهٔ نور بالایی و سایهٔ ته؛ رنگ دکمه معنی دارد (سبز = ادامه، نارنجی = مهم، آبی = ثانویه).
3. **قاب‌ها و ربان‌ها:** عنوان‌ها روی ربان با لبهٔ ضخیم؛ پنل‌ها با گوشه گرد و حاشیهٔ دورنگ.
4. **منبع‌ها:** سکه/الماس/قلب بالا با آیکون براق و عدد درشت؛ دکمهٔ «+» کنارشان.
5. **جایزه:** باز کردن صندوق با درخشش و ذره؛ ستاره‌ها با انیمیشن پشت‌سرهم.
6. **نقشه:** مسیر پیچ‌پیچ با گره‌های مرحله؛ مراحل بسته با قفل.
7. **فروشگاه:** برگه‌ها؛ کالاهای بزرگ با تخفیف روی ربان.

## ۲. اصول برای بازی ما

| اصل | پیاده‌سازی |
|---|---|
| بالا و پایین براق | nine-patch شیشه‌ای از `tools/ui_art.py` |
| معنی رنگی دکمه | سبز ادامه، نارنجی خرید/مهم، آبی انتخاب، بنفش ویژه |
| بازخورد پاداش | هر پاداش ذره + صدا + عدد شمارنده |
| خوانایی | متن تیره روی پنل روشن یا سفید با خط دور روی تیره |
| هویت خودمان | رنگارستان + ساعت/لنز + قاب‌های زمان؛ **هیچ شکل یا آیکون از آن بازی** |

## ۳. چیزهایی که کپی نمی‌شود
چیدمان دقیق، شکل دکمه‌ها و ربان‌ها، آیکون‌ها، رنگ‌بندی دقیق، شخصیت‌ها، لوگو، هر متن یا نام.

## ۴. تفاوت‌های ما
دو زمان در هر صفحه (شبح لایه)، لنز، قاب‌های ساعتی، کتاب خاطره، شخصیت‌های ایرانی، متن راست‌به‌چپ.

## ۵. رویه
هر صفحه: **صاحب پروژه طرح می‌دهد** ← پیاده‌سازی عین طرح ← اسکرین‌شات کنار طرح ← تأیید. این سند فقط برای ثابت ماندن حس کلی است.
