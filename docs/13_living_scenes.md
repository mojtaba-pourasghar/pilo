# صحنه‌های زنده: فهرست هر فصل

برای هر فصل: **حرکت طبیعت / جریان ذره / نور متغیر** در گذشته و حال (قاعدهٔ [13](13_camera_and_living_world.md)).

| فصل | گذشته | حال |
|---|---|---|
| ۱ جنگل | آبشار جاری، سنجاقک‌ها، پرتو نور میان برگ | آبشار خشک، برگ‌های خاکستری می‌افتند، نور کم |
| ۲ ساحل | موج‌های آبی، حباب‌ها، مرجان درخشان | ماسهٔ خشک، گردوغبار، نور ملایم |
| ۳ بیابان | واحهٔ پرآب، نخل‌های تکان‌خور، چشمک آب | شن روان، طوفان، سراب |
| ۴ کوهستان | چمن و آب، پرستوها | برف، یخ بلور، باد |
| ۵ آسمان | رنگین‌کمان، بادبادک‌ها، ابر نرم | ابر رعدی، برق |
| ۶ بازار | رهگذر شبح‌وار، آواز، فانوس | غبار، پارچه‌های آویزان |
| ۷ غار | بلورهای روشن، کرم شب‌تاب | تاریکی، چکه، بلور خاموش |
| ۸ سبزدره | گندم‌زار، چراغ جشن | مه، نیمه‌محو، جرقهٔ خاطره |
| ۹ کارخانه | چرخ‌دنده‌ها می‌چرخند، بخار | زنگار، چکه، چرخ ایستاده |
| ۱۰ کتابخانه | کتاب‌های پرنده، جوهر زنده | گرد و خاک، کتاب افتاده |
| ۱۱ قلعه | شب آرام، ستاره‌های پشت پنجره | سایه‌های ولگرد |
| ۱۲ کارگاه | کوره‌ها روشن، جرقه | خاکستر، سرد |
| ۱۳ دریای ستاره | ستاره‌ها زنده، شهاب | سیاه و ساکت |
| ۱۴ وارونه | هر دو: ریزش معکوس، آب بالا می‌رود | |
| ۱۵ قلب ساعت | نور طلایی، چرخ‌دنده‌های نور | همان؛ کم‌کم هماهنگ |

**هاب:** رنگ به‌تدریج برمی‌گردد (۸ مرحله بر اساس قلب‌ها)؛ مرغ‌ها، مردم، دود بخاری، پرندهٔ نمادین.
