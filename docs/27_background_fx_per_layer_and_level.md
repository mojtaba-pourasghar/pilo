# افکت‌های هر لایهٔ پس‌زمینه و هر مرحله

> مکمل `docs/21` §۴ و `docs/22` §۵. پس‌زمینه «زنده» است؛ هر لایه حرکت و افکت دارد. همه شیدرها سبک و ۳ سطح کیفیت دارند.

## ۱. افکت پایه هر لایه
| لایه | نقش | افکت‌ها |
|---|---|---|
| **L0 آسمان** | رنگ و نور | رشد آرام گرادیان (۶۰ث)، ابر می‌رود (۰٫۰۲ ضریب)، **درخشش خورشید** (add)، پرنده‌های دور |
| **L1 سیلوئت دور** | کوه/قلعه | **مه جوی** (add، ۰٫۴)، برج‌ها و پرچم‌های ریز تاب‌دار |
| **L2 مه‌آلود** | تپه/آبشار دور | مه لایه‌ای، **تار شدن عمق** (blur ۲px)، آبشار با رنگ‌پاشی |
| **L3 میانی** | تنه/طاق | **پرتوهای نور** (god rays، add، حرکت ۰٫۰۵Hz)، گرده‌های معلق |
| **L4 نزدیک** | درخت/ستون | **تاب باد** (شیدر `vertex wind`، دامنه ۳px)، برگ‌های افتان |
| **L5 بازی** | زمین | **چمن واکنشی** (خم می‌شود با عبور)، گرد، لرزش پل/تخته، ردپا، موج آب |
| **L6 جلو** | سیلوئت تیره | **تاب شدیدتر** (۶px)، کرم‌شب‌تاب جلوی دوربین (تار)، تاریکی حاشیه (vignette) |
**رنگ‌بندی دوره‌ای** (شیدر پایان): قدیم = طلایی/گرم؛ جدید = فیروزه‌ای/بنفش‌دود؛ هر دو با **تفاوت مه** و **ذرات**.
**مه و عمق:** هر لایه رنگ مه خودش را دارد (دورتر: آبی-بنفش روشن‌تر)؛ **blur عمقی** روی L0–L1 و L6.

## ۲. افکت هر مرحله (۱۲ مرحله)
| مرحله | افکت‌های محیطی یکتا (علاوه بر پایه) |
|---|---|
| ۱-ق دشت صبح | پروانهٔ کوچک، گل‌های رقصان، شبنم می‌درخشد، پرندگان، ابر آرام |
| ۱-ج دشت بعد | دود بنفش کم‌رنگ از ویرانه، آتش‌پاره‌های ریز، نور غروبی، کشتی دود دور |
| ۲-ق دره | **رودخانه با جریان** (شیدر)، کنده‌ها می‌افتند (چلپ‌چلپ)، مه آبی |
| ۲-ج پل | تخته‌ها می‌لرزند، خاک می‌ریزد، پرچم‌های رنگی، **حباب** هنگام سقوط |
| ۳-ق سد | آب فشار، کف، قطره‌های پرتاب، لرزش ۰٫۲ هنگام شکستن |
| ۳-ج آبشار | **مه آبشار** (add)، رنگین‌کمان، قطره‌های روی لنز، موج برگشت |
| ۴-ق تونل | قطرهٔ آب سقف، کرم‌شب‌تاب، **فانوس** (نور پویا با سایه)، ریشه‌های چرخان با جرقه |
| ۴-ج درخت | **پرتو از لای شاخه‌ها**، برگ‌ریز، باد صعودی؛ در سقوط **خطوط سرعت** و ابرها |
| ۵-ق شب | کلاهک‌های قارچ **نبض نور**، کرم‌شب‌تاب، ستاره، موسیقی نورانی |
| ۵-ج غار | قارچ‌های درخشان، پیلو-فانوس (نور و سایه)، ریشه‌چرخان‌ها |
| ۶-ق غار | دهانهٔ نور با پرتو، خاک معلق، لرزش دور ۰٫۱ |
| ۶-ج لانه | **دود بنفش** فاز ۲، موج زمین، سنگ‌ریزه، **پروانه‌های** آزادی، نور طلایی هنگام لالایی |

## ۳. افکت‌های واکنشی با بازیکن
- **چمن/برگ:** خم می‌شود و برمی‌گردد (۰٫۳ث)، **ذرهٔ برگ** هنگام دویدن در بوته.
- **آب:** حلقه هنگام فرود/عبور، چکه، موج.
- **گرد/خاک:** هنگام ترمز/فرود.
- **تخته/پل:** خمیدگی ۲–۴px با وزن، خرده‌چوب.
- **نور:** سایهٔ نرم قهرمان روی زمین؛ در غار، فانوس سایهٔ پویا.

## ۴. بودجه
هر صفحه ≤ ۲۰۰ ذره، ≤ ۶ شیدر تمام‌صفحه؛ در کیفیت کم: مه و blur و god rays خاموش، باد ساده.

## ۵. هنر لازم
۶ لایه برای هر یک از ۱۲ مرحله (ردیف §۲ حاکم)؛ ماسک پرتو، ماسک مه، پلت برگ‌های افتان؛ پلت افکت (ذره نور، قطره، تکه چوب، پروانه).
