# پرامت شروع برای Claude Code (نگهبانان زمان)

کپی کن و بده به Claude Code:

---
پروژهٔ «نگهبانان زمان» (Godot 4.3/GDScript؛ مخزن `pilo`). اول `CLAUDE.md` را بخوان، سپس به این ترتیب:
1. `docs/BUILD_BRIEF.md` (ورودی اصلی؛ گام‌های T0–T20)
2. `docs/SCENARIO.md` (مرجع داستان)
3. `docs/02_godot_spec.md` (مشخصات فنی)
4. `docs/03_levels_ch1-15.md`
5. `docs/content/*` (فصل‌ها، قهرمان‌ها، همراه‌ها، کلید، سلاح، اقتصاد)
6. `docs/DECISIONS.md`، `docs/15_work_log_claude_code.md`، `comms/*`

**خلاصهٔ بازی:** پلتفرمر معمایی-ماجرایی دوبعدی؛ **گذشته و حال با هم** (دو لایهٔ هم‌زمان با لنز)؛ هر مرحله دو کلید با جای تصادفی و یک پاسدار با راز؛ نگهبان فصل با فاز؛ ۱۲ قهرمان، ۱۶ همراه، سلاح ارتقاپذیر؛ رقیب = بازیکنان دیگر (مسابقهٔ روح)؛ سن ۸ تا ۱۵.

**موتور فعلی کار می‌کند؛ تکاملش بده، از صفر ننویس.** هر گام: کد + تست + کامیت «گام N: …» + به‌روزرسانی `docs/15_work_log_claude_code.md` و `comms/CODE_STATUS.md`.

**شروع:** گام T0 (تغییر نام نیما←آرسام، حذف کیان، نام پروژه)، بعد T3 تا T8 تا فصل ۱ کامل بازی‌شدنی شود. بعد از T8 بایست و گزارش بده تا صاحب پروژه بازی‌تست کند.

**قواعد ثابت (CLAUDE.md):** صفحه‌ها فقط عین طرح صاحب پروژه (بدون طرح نساز)؛ هنر کدساخته فقط `art/drafts/`؛ اگر مشخصات تناقض داشت بایست و بپرس (`comms/DECISION_QUEUE.md`)؛ هیچ کلید/توکن در مخزن؛ صدا بدون نام قهرمان؛ ضبط انسانی بازنویسی نشود. قبل از هر کامیت: `python3 tests/validate_levels.py` و `godot --headless --path . res://tests/test_runner.tscn`.
در پایان هر گام گزارش کوتاه بده: چه ساخته شد، چه تست شد، چه چیزی لازم است.
