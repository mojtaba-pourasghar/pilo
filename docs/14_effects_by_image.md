# افکت‌ها

## قواعد
1. هر افکت **از روی تصویر یا اسپرایت‌شیت** ساخته می‌شود، نه با شکل ساده کد (کد فقط ذره‌های جانبی).
2. هر افکت: نام، نمونه‌شمار، اندازه، مدت، رنگ عنصر.
3. مناسب ۸ تا ۱۵ سال: بدون خون؛ سقف چشمک.
4. پرامپت تصویر فقط **متنی** است؛ هیچ تصویر مرجع از بازی دیگر داده نمی‌شود.

## نمونه پرامپت متنی
«افکت حلقهٔ لنز: حلقه نور طلایی-آبی با ذره‌های ساعت‌مانند، پس‌زمینهٔ شفاف، ۸ فریم، نمای روبرو، سبک براق و شیشه‌ای.»

## زوم و وضوح
اسپرایت‌ها در رزولوشن ۲× ساخته و کوچک می‌شوند؛ `nearest` فقط برای پیکسل؛ این بازی نقاشی‌وار است، فیلتر خطی.
