# هاب، منوها و جریان صفحه‌ها

> وضعیت: **پیش‌نویس ساختار (بدون شکل)**. طبق قانون پروژه، **شکل و چیدمان هر صفحه را صاحب پروژه طراحی می‌کند** و تصویرش را می‌دهد؛ این فایل فقط فهرست صفحه‌ها و محتوایشان است تا طراح بداند چه چیزی باید طراحی شود. مرجع ظاهری: اسکرین‌شات‌های «ساختمان‌شکن‌ها» که صاحب پروژه فرستاده (فقط الهام، نه کپی).

## ۱. جریان کلی

```
شروع بازی → [تعریف/آموزش در اولین بار] → هاب (دهکده)
هاب → نقشهٔ فصل‌ها → کارت پیش‌نمایش فصل → فهرست مرحله‌ها → آماده‌سازی → مرحله → نتیجه
هاب → قهرمان‌ها / همراه‌ها / کارگاه / فروشگاه / رویدادها / روزانه / رقیب‌ها / تنظیمات
```

## ۳. اصول رابط (بدون طرح)

- جهت **راست‌به‌چپ**، فونت فارسی خوانا، دکمه‌های بزرگ برای انگشت کودک.
- هر صفحه **یک کار اصلی** دارد.
- رنگ جهان هر فصل در صفحهٔ آن فصل دیده می‌شود (فصل‌ها در فایل‌ها: «رنگ جهان»).
- **ابزار فوری** در HUD (فایل ۰۷).
- متن‌ها فقط از فایل‌های داستان و قفسه‌ها (فارسی یکدست؛ اصطلاحات SCENARIO بخش ۱۱).

## ۴. فرایند طراحی صفحه‌ها (طبق CLAUDE.md)

1. صاحب پروژه طرح (تصویر) را می‌دهد.
2. کلود **عین طرح** را می‌سازد (چیدمان، اندازه، رنگ، سبک، متن).
3. اگر تضاد فنی بود: نزدیک‌ترین نسخهٔ وفادار + گزارش صریح + سؤال.
4. از صفحه اسکرین‌شات می‌گیرد و کنار طرح می‌گذارد (`tools/screenshot.tscn`).
5. تأیید صاحب پروژه ← کامیت.

> **در این فاز هنوز هیچ صفحه‌ای ساخته نمی‌شود.**
