## ۲. مصوبات بازار

- کافه‌بازار و مایکت؛ پرداخت درون‌برنامه‌ای با SDK بازار (Poolakey برای کافه‌بازار)؛ قیمت‌ها به تومان.
- تبلیغ پاداشی: Adivery (اختیاری، سقف ۵ در روز).
- **حریم خصوصی:** با اضافه شدن تبلیغ/خرید/آنلاین، متن README و صفحهٔ «درباره» باید عوض شود («کاملاً آفلاین و بی‌تبلیغ» دیگر درست نیست).
- سقف سنی: مناسب ۸+؛ بدون چت آزاد؛ بدون جعبه‌شانس پولی.
- بدون بخش «بزرگ‌ترها» (تصمیم صاحب پروژه)؛ سد ساده‌ٔ تأیید خرید می‌ماند.

## ۳. معیار پذیرش v1

1. ۴۰ مرحله از `tests/validate_levels.py` (۹ ترکیب کلید) سبز.
2. `test_runner` سبز (سیستم‌های جدید دارای تست).
3. هر ۶ قهرمان و همراه‌هایشان حرکت و حالت‌های جدا دارند.
4. هر ۴۰ مرحله پاسدار دارد و راز آن در مرحله سرنخ دارد.
5. اقتصاد: بازیکنی بدون خرید فصل ۱–۵ را کامل می‌کند.
6. طرح‌های صفحه‌های اصلی از صاحب پروژه رسیده و عین آن ساخته شده، با اسکرین‌شات مقایسه.
7. اجرا روی گوشی میان‌رده ≥ ۳۰fps.
8. هیچ توکن/کلیدی در مخزن نیست.
