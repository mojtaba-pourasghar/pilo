# خاطره‌ها، تخم‌ها و مجموعه‌ها

> جایگزین سند «نامه‌ها و بازماندگان» پروژهٔ دیگر؛ برای این بازی، مجموعه‌های داستانی همین‌هاست.

## ۱. ۱۵ خاطره

- هر فصل یک **اتاق خاطره** (مرحلهٔ ۷) دارد؛ خاطره یک **کلید نقره‌ای** و یک صحنهٔ کوتاه (۱۰–۲۰ ثانیه) است.
- ۱۵ خاطره ← اپیلوگ: رنگ ویژهٔ قلب نهم + زروان قهرمان دوازدهم ([SCENARIO §10](SCENARIO.md)).
- دفترچهٔ خاطره (`MemoryBook`): نمایش هر خاطره با تصویر و متن کوتاه؛ دوباره‌دیدن ممکن.

| فصل | خاطره |
|---|---|
| ۱ | قارچ‌شاه و اولین باران |
| ۲ | ناخدا موج و دخترش |
| ۳ | گل‌نارِ کوچک و اولین رقص |
| ۴ | سیمین و برفک |
| ۵ | غبارک در شب ماجرا |
| ۶ | آرش و دفتر پدر |
| ۷ | نوا و اولین بلور |
| ۸ | مادربزرگِ دختربچه در جشن سبزدره |
| ۹ | بابابزرگ و زروانِ نوجوان |
| ۱۰ | روز طوفان سپیدار |
| ۱۱ | شاه‌سایه و بچه‌ای که از تاریکی می‌ترسید |
| ۱۲ | آذر و اولین کلید شکسته |
| ۱۳ | ستاره و دریانوردی که دهکده‌اش را جست |
| ۱۴ | زروان و اولین ساعت |
| ۱۵ | بابابزرگ و تخمی که ساخت |

## ۲. تخم‌ها (۱۵)

جدول در [content/05_companions §۶](content/05_companions.md). هر تخم در فصل مشخص (اتاق خاطره یا نگهبان) پنهان است؛ در «لانه» جوجه می‌شود (زمان واقعی کوتاه: ۱–۱۰ دقیقه؛ با الماس فوری).

## ۳. کلیدها

| کلید | کاربرد |
|---|---|
| کلید گذشته / حال | دروازهٔ مرحله |
| کلید نقره‌ای | خاطره |
| کلید طلایی | جایزهٔ شکست نگهبان؛ اتاق جایزه |
| کلیدهای راز | رویداد میان‌زمان (فایل [08](content/08_secret_keys_live_event.md)) |

## ۵. دفتر شناخت پاسدارها

هر بار پاسداری را شکست دهی، «راز» او در دفتر نوشته می‌شود؛ بازیکن جدید می‌تواند قبل از مرحله نگاه کند (پاداش دانش، نه اجبار).
