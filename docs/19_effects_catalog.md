## ۰. قالب هر افکت

| فیلد | توضیح |
|---|---|
| **id** | `fx_<دسته>_<نام>` |
| **فریم / FPS** | معمولاً ۶–۱۲ فریم، ۱۲ تا ۲۴ FPS |
| **اندازه** | نسبت به خانه (۶۴px) |
| **مدت** | ثانیه |
| **رنگ** | پالت فایل ۰۴؛ عنصر: آتش `#FF7A3D` آب `#3DA9FF` گیاه `#4CC36B` باد `#B7E3F2` نور `#FFE066` سایه `#6B4FA8`؛ گذشته `#8FD3FF`؛ حال `#FFB27A` |
| **لایه** | پشت/جلوی قهرمان، بالای HUD (فقط افکت‌های مهم) |
| **پرامپت** | متنِ تولید تصویر (فارسی/انگلیسی)، پس‌زمینهٔ شفاف |

> **اسپرایت دو رنگ:** هر افکت رنگ‌پذیر است (یک نسخه، رنگ عنصر با shader). اولویت: حجم کم.

## ۵. سلاح‌ها

### ۵.۱. سطح‌ها (ضربه ۴–۶ فریم، ۰٫۲ث؛ رنگ سطح)
| سطح | رنگ لبه | اثر |
|---|---|---|
| ۱ ساده | قهوه‌ای | جرقه ساده |
| ۲ آبدیده | آهنی | جرقهٔ نقره‌ای |
| ۳ ورزیده | نقره‌ای | خط نور |
| ۴ افسانه‌ای | طلایی | خط درخشان + ذره |
| ۵ زمان‌دار | شفاف/چرخان | ردِ ساعتی؛ دو رنگ (گذشته/حال) |

### ۵.۲. ویژگی هر سلاح (id: `fx_w_<نام>`؛ رنگ‌پذیر)
کمان لنز (رد دو رنگ) · نیزهٔ مرجانی (حباب) · روبان باد (خط حلقوی) · تیغهٔ سپیده (کریستال) · کیسهٔ غبار (ابر) · کیف تله (دایره‌ٔ تله) · نای بلور (نت و موج) · جعبه‌ابزار (چرخ‌دنده) · شمشیر شب (برش تیره) · چکش آذر (لرزه، جرقه) · ستاره‌پران (ستارهٔ چرخان) · عقربهٔ وارونه (عقربه‌های دو رو).
- **ضربهٔ شارژی:** ۸ فریم؛ حلقهٔ پرشدن دور قهرمان.
- **ضربهٔ هوایی:** رد کوتاه + غبار فرود.

### ۵.۳. مودها
شکل تیر (ستاره، پر، قلب، ساعت، شهاب): هر یک ردِ پرتاب خاص. اثرها: کندکننده (دایرهٔ یخ‌ریز)، زنجیره‌ای (قوس برق)، برگشتی (کمان بازگشت)، دو زمان (دو ردِ هم‌زمان)، بازتابی (شعاع)، پیداکن (دایرهٔ جستجو).

## ۱۰. تولید
1. هر دسته یک **برگهٔ مرجع** (`docs/design_sheets/effects_hud.md`، گام B8) با پرامپت متنی و اندازه.
2. اسپرایت‌شیت `art_src/fx/<id>.png`؛ نقشهٔ اتصال `data/fx.json` (T1).
3. اولویت v1 (پردهٔ ۱): زمان و کلید، ۶ عنصر، توان ۴ قهرمان v1، فرمان ۴ همراه، سطح ۱–۳ سلاح، ۱۲ ابزار، پاسدار، نگهبان ۱–۵، رابط.
