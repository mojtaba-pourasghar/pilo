> **ایمنی کودک:** هیچ سلاحی خون یا زخم نمی‌سازد؛ ضربه = «آزاد کردن» دشمن (بی‌حال شدن، درخشش، کوچک شدن).

## ۱. فرمول آسیب

```
آسیب = پایه × ضریب سطح × ضریب عنصر × (۱ + مودها) × بحرانی × سقف رقابت
```

| جزء | مقدار |
|---|---|
| ضریب سطح | ۱ / ۱٫۲۵ / ۱٫۵ / ۲ / ۲٫۵ (سطح ۱ تا ۵) |
| ضریب عنصر | قوی ×۱٫۵؛ ضعیف ×۰٫۷۵؛ بقیه ×۱ |
| بحرانی | ×۱٫۵ (نقطهٔ ضعف / ضربه از پشت شاه‌سایه ×۲) |
| سلاح کم‌سطح در جای نیازمند سطح | ×۰٫۲ (هشدار + دکمهٔ «برو کارگاه»؛ ممنوع نیست) |
| سقف رقابت آنلاین | آسیب به سقف مشترک تنظیم می‌شود (ضد pay-to-win) |

نکته: «تعداد ضربه برای پاسدار/نگهبان» در [فایل ۰۶](06_keys_and_keepers.md) **ثابت** است؛ سطح بالاتر یعنی **سریع‌تر، امن‌تر و زیباتر**، نه «حل‌نشدنی بدون آن» (جز K9 و فصل‌های جدول سطح).

## ۲. چطور سلاح قدرتمند می‌شود (چهار راه)

| راه | چه می‌شود | جا | نیاز |
|---|---|---|---|
| **۱. سطح (۱ تا ۵)** | ضریب آسیب، جای مود، ظاهر، اثر | کارگاه بابابزرگ (بعد فصل ۹)، کارگاه آذر (فصل ۱۲)؛ سطح ۱–۳ در کارگاه هاب از اول | سکه + مواد (آهن، نقره، قطعهٔ نگهبان، ذرهٔ زمان) |
| **۲. مود** | شکل، عنصر، اثر | کارگاه / «میز مود» | مود از مرحله، صندوق، جایزهٔ پاسدار؛ **قابل‌برداشتن و انتقال** |
| **۳. تیزی (مهارت سلاح)** | هر سلاح با استفادهٔ بیشتر ۵ «نشان تیزی» می‌گیرد: هر نشان +۲٪ آسیب یا +۳٪ سرعت (انتخابی) | خودکار | بازی با آن سلاح (۲۰۰ ضربهٔ موثر/نشان) |
| **۴. ظاهر** | رنگ، نقش، درخشش، صدا | «ویترین سلاح» | سکه / رویداد؛ **قدرت ندارد** |

- ارتقای سلاح **فوری** است (بدون انتظار ساعتی).
- مواد با بازی عادی می‌آید؛ **هیچ مادهٔ ارتقا فقط با پول واقعی نیست** (بستهٔ مواد فقط میان‌بر).
- **سقف:** سلاح پایه تا سطح ۳؛ سلاح ویژهٔ قهرمان تا ۵.

## ۵. مودها (سفارشی‌سازی)

**جای مود:** سطح ۱ و ۲ = ۰، سطح ۳ = ۱، سطح ۴ = ۲، سطح ۵ = ۳. هر مود قابل‌برداشتن و انتقال است.

### ۵.۱. شکل (ظاهر + اثر کوچک)
تیر ساده · تیر ستاره (کمی بُرد) · تیر پر (سرعت) · تیر قلب (بر دشمن «آرام» می‌نشاند) · تیر ساعت (۰٫۵ ثانیه کندکننده) · تیر شهاب (دنباله‌ٔ نورانی). برای سلاح‌های نزدیک: **شکل تیغ/سر** (شمشیر سبز، چماق گلی…).

### ۵.۲. عنصر (جوهر)
جوهر آتش، آب، گیاه، باد، نور، سایه ← تغییر عنصر ضربه؛ جدول در [۰۷](07_combat_weapons_upgrades.md). (قهرمان عنصر خودش را رایگان دارد؛ جوهر بعد از گذاشتن «ترکیب» می‌دهد: مثلاً آتش + باد = شعلهٔ پراکنده.)

### ۵.۳. اثر
| اثر | رفتار |
|---|---|
| **کندکننده** | ۱ ثانیه سرعت دشمن ×۰٫۶ |
| **زنجیره‌ای** | ضربه به دشمن بعدی هم می‌رسد (۵۰٪) |
| **برگشتی** | سلاح پرتابی برمی‌گردد و یک ضربهٔ دیگر |
| **دو زمان** | ضربه در لایهٔ دیگر هم اثر (۳۰٪) — فقط سطح ۴ به بالا |
| **سبک‌ساز** | هزینهٔ شارژ لنز −۵ برای هر ضربهٔ موثر |
| **بازتابی** | نور/آینه را برمی‌گرداند (K2) |
| **پیدا‌کن** | ضربه به پاسدار پنهان (K8) را نشانه‌گذاری می‌کند |
| **قلب‌دار** | ۵٪ شانس قلب خردهٔ جایزه |

(فهرست قابل‌افزودن در `data/mods.json`؛ ≥ ۲۰ مود در v1 و بیشتر با رویداد.)

### ۶.۲. قدرتمندشدن ابزار (سطح ۱ تا ۵)
هر ابزار ۵ سطح مثل سلاح؛ سطح بالاتر ← **ظرفیت بیشتر، مدت بیشتر، اثر جانبی، ظاهر**.

| سطح | ظرفیت (بار) | مدت/برد | نیاز |
|---|---|---|---|
| ۱ | پایه | پایه | رایگان |
| ۲ | +۱ | +۱۰٪ | سکه + ۲ آهن |
| ۳ | +۱ | +۲۵٪ + اثر جانبی کوچک | سکه + ۳ نقره |
| ۴ | +۲ | +۵۰٪ + اثر جانبی | سکه + «قطعهٔ ابزار» (از نگهبان) |
| ۵ | +۳ | +۱۰۰٪ + **اثر دو زمان** | سکه + قطعهٔ ویژه (فصل ۱۲+) |

**اثر جانبی** (نمونه): آینه ← تابش به دو هدف؛ طناب ← جابه‌جایی صندوق؛ بمب دودی ← ۲ ثانیه شیدا؛ فانوس ← ردپا؛ قلاب ← کشیدن سکه‌ها؛ مهره‌ها ← منطقهٔ بزرگ‌تر؛ کوک ← دو سازوکار؛ نقشه ← ۸ ثانیه + جهت؛ ساعت جیبی ← ۵ ثانیه؛ سپر ← بازتاب ضربه؛ تیرکمان‌پشتی ← ظرفیت ۶۰.
- **اثر دو زمان:** ابزار در هر دو لایه هم‌زمان اثر می‌کند (مثلاً آینه‌ای که تابش را در گذشته و حال می‌اندازد).
- ظرفیت **در مرحله** تازه می‌شود (نه فقط شروع بازی)، مگر ابزار «مصرفی» (بمب دودی، مهره‌ها) که با سکه یا مرحله پر می‌شود.

### ۶.۳. ترکیب‌ها (کشف بازیکن)
- **آینه + فانوس** ← پرتو بلند؛ **مهرهٔ یخ + طناب** ← پل یخی آویزان؛ **بمب دودی + نیزه‌پرتاب** ← ضربهٔ پنهان؛ **قلاب + ساعت جیبی** ← پرش مرگبار آهسته؛ **مهرهٔ شعله + مودِ باد** ← شعلهٔ پخش‌شونده. (در `data/combos.json`؛ راهنمای مرحله فقط اشاره می‌کند، مثل کشف.)
