# حالت خودکار مدیر (بدون پرسش از صاحب پروژه)

دستور صاحب پروژه (۱۶ نوامبر): همهٔ موارد را **خودکار** انجام بده؛ **توقف نکن**؛ هر طرح که خوب نیست **دوباره بزن**؛ همه‌چیز را **ذخیره کن**؛ هر بار نگو.

## چرخهٔ هر دسته
1. پرامپت (پیشوند سبک + توضیح + پسوند) ← `docs/design_sheets/prompts/`.
2. ساخت در Canva ← poll ← پیش‌نمایش در `previews/` ← لینک در `CANVA_LINKS.md`.
3. **کنترل کیفیت** (مدیر): چیدمان درست؟ شخصیت هم‌خوان؟ متن/عدد داخل تصویر نیست؟ قطعه‌ها جدا و قابل برش؟ تضاد دو زمان درست؟ ← اگر نه: **بازتولید** با پرامپت بهتر؛ ثبت دلیل در جدول زیر.
4. فایل کامل را صاحب پروژه هر وقت فرستاد ← برش (`tools/art/slice_sheets.py`) ← draft ← commit/push.
5. محدودیت سهمیهٔ Canva («cooling down»): پرامپت‌ها در `prompts/queue/` می‌مانند؛ بعداً دوباره اجرا می‌شود.
