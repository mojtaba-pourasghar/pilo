# بایبل هنر و صدا

> **قانون پروژه:** صاحب پروژه طرح هر صفحه را می‌دهد و **عین آن** ساخته می‌شود ([CLAUDE.md](../CLAUDE.md)). این بایبل برای «هنر اجزا» (شخصیت، محیط، افکت، صدا) است، نه چیدمان صفحه‌ها.
> هیچ‌چیز از بازی دیگر کپی نمی‌شود؛ تصویر بازی‌های دیگر به مدل تصویر داده نمی‌شود، فقط توضیح متنی سبک.

## ۱. سبک کلی

| مورد | تصمیم |
|---|---|
| حس | روشن، شاد، براق؛ دنیای رنگ‌های زنده (رنگارستان)؛ برای ۸ تا ۱۵ سال، کمی «ماجراجویی نوجوانانه» نه «نوزادی» |
| رابط | شیشه‌ای و براق (دکمه‌ها، قاب‌ها، ربان‌ها)، لبهٔ نور، سایهٔ نرم؛ الهام از سبک «ساختمان‌شکن‌ها»، **بدون کپی** (فایل [10](10_reference_analysis_castle_busters_style.md)) |
| شخصیت‌ها | نقاشی‌وار سه‌بعدی‌نما، پرجزئیات؛ **حالت‌های جدا** و حرکت طبیعی؛ از همهٔ زاویه‌ها قابل‌قبول |
| مقیاس | ۱۲۸۰×۷۲۰؛ خانه ۶۴px؛ قد قهرمان ~۸۰px بدنه |
| روش تولید | موجود: `tools/art/*` (FLUX از طریق Cloudflare)، `tools/ui_art.py`، `art_src/`؛ ساخت با کد فقط جانگهدار در `art/drafts/` |
| دو زمان | **گذشته:** رنگ گرم‌تر، قدیمی‌تر، با لبهٔ آبی روشن؛ **حال:** رنگ خسته‌تر ولی هنوز زنده، لبهٔ نارنجی. شبح لایهٔ غایب: آلفا ۰٫۳۵ |

## ۴. شخصیت‌ها (برای هنرمند)

برای هر کدام یک **برگهٔ مرجع** (سه‌چهارم، نیم‌رخ، پشت، چهره‌ها) و **فهرست حالت‌ها**: ایستاده، راه، دویدن، پرش، فرود، سر خوردن، ضربه، جاخالی، توان ویژه، آسیب، جشن، خستگی، بیکاری ۱، بیکاری ۲.

| قهرمان | ظاهر (خلاصه) | رنگ اصلی |
|---|---|---|
| آرسام (۱۲) | پسر کنجکاو، لنز آویخته به گردن، شال ساده | آبی و زرد |
| ماهک (۱۱) | دختر دریایی، موی بافته با صدف، پوست برنزه | آبی فیروزه |
| گل‌نار (۱۲) | رقصنده با روبان بلند، لباس شنی | سرخ و طلایی |
| سیمین (۱۳) | دختر کوهستان، کلاه پشمی، تیغهٔ یخی | سفید و آبی |
| غبارک | موجود غباری کوچک با چشم‌های درشت | خاکستری روشن |
| آرش (۱۳) | بازرگان جوان، کیف تله، شال رنگی | سبز و قهوه‌ای |
| نوا (۱۱) | دختر غار، موهای بلند، نای بلورین | بنفش |
| ساعتک | ربات ساعت‌ساز کوچک، صورت ساعت | مسی |
| شاه‌سایه | قامت بلند سایه‌وار، شمشیر شب، مهربان | بنفش تیره |
| آذر (۱۳) | آهنگر جوان، چکش بزرگ، پیش‌بند | قرمز |
| ستاره (۱۲) | ناخدای ستاره‌ای، شنل پر ستاره | آبی شب |
| زروان (۳۲) | مرد غمگین، لباس ساعت‌ساز، نقاب افتاده | خاکستری و بنفش |

همراه‌ها: برگ‌های مرجع و ۳ شکل برای هر ۱۶ همراه (جدول [content/05](content/05_companions.md)). پیلو **روباه** است.
نگهبان‌ها: ۱۵ طرح (خرس پیر، اختاپوس، کرم شنی، غول یخی، عقاب طوفان، قفل‌بان، عنکبوت بلورین، مجسمه، بابابزرگ طلسم‌شده، کتابدار، شاه‌سایه، آتش‌دان، کلاغ‌ساعت، زروان…). پاسدارها ۱۲ نوع پایه × پوست هر فصل.

## ۵. فهرست دارایی‌ها (دسته‌ها)

1. رابط: دکمه‌ها، پنل‌ها، ربان‌ها، قاب‌ها، نوار جان، آیکون‌ها (کیت UI؛ `tools/ui_art.py`).
2. شخصیت‌ها و همراه‌ها (rig + حالت‌ها).
3. دشمن‌ها و پاسدارها و نگهبان‌ها.
4. محیط هر فصل: پس‌زمینهٔ چندلایه (دور/میانی/نزدیک) × ۲ زمان، کاشی‌ها، اشیای تعاملی.
5. اشیا: کلید (گذشته/حال/نقره‌ای/طلایی)، تخم‌ها، قلب‌ها، سکه، الماس، مواد، جعبه‌ها، صندوق‌ها.
6. سلاح‌ها (۵ پایه + ۱۲ ویژه × ۵ سطح) و ابزار (۱۲)؛ شکل تیرها.
7. افکت‌ها ([14](14_effects_by_image.md)).
8. صحنه‌های داستان و کارت فصل (۱۵) و پایان‌ها.

## ۶. صدا

| بخش | قاعده |
|---|---|
| موسیقی | هر فصل یک تم + نسخهٔ «گذشته» (نرم‌تر، سازهای آکوستیک) و «حال» (خسته‌تر)؛ تم نبرد؛ تم هاب؛ تم پایان. سازهای ایرانی (سنتور، نی، تار) در تم‌های فرعی |
| محیط | ضبط واقعی از Commons با `tools/audio/fetch_ambience.py` (منبع/مجوز در `docs/audio/sound_sources.json`)، وگرنه `synth_ambience.py` |
| جلوه‌ها | `tools/audio.py`: ضربه، کلید، لنز، جعبه، سکه، قلب، ارتقا، باز شدن صندوق |
| صدای شخصیت | هر شخصیت صدای خودش (آواشو، `tools/voice-studio`)؛ **نام قهرمان گفته نمی‌شود**؛ ضبط انسانی بازنویسی نشود |
| لنز | صدای جابه‌جایی گذشته/حال: «ویژ» نرم + زنگ ساعت |

## ۷. ممنوع

- کپی از بازی/شخصیت دیگر.
- هنر کدساخته به‌عنوان نهایی.
- خشونت واقعی و خون.
- متن فارسی داخل تصویر (متن‌ها با فونت و کد).
