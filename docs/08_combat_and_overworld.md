# جنگ و هاب (دنیای اصلی)

> مرجع داده: [content/07](content/07_combat_weapons_upgrades.md) (سلاح‌ها، سطح‌ها، عنصرها). اینجا قواعد اجرایی برای موتور است.

## ۱. جنگ

### ۱.۱ سیستم زنده (نه نوبتی)
جنگ همزمان با پلتفرم است: ضربه، جاخالی، توان، ابزار، فرمان همراه، لنز.

| ورودی | عمل |
|---|---|
| دکمهٔ حمله | ضربهٔ سلاح فعال؛ نگه‌داشتن = ضربهٔ شارژی |
| دکمهٔ پرش | پرش (دوتایی برای آرسام) |
| دکمهٔ دش | دش/جاخالی (وقفه ۰٫۴۵ث؛ موجود) |
| دکمهٔ توان | توان ویژهٔ قهرمان (شارژ) |
| دکمهٔ لنز | عوض‌کردن گذشته/حال |
| دکمهٔ همراه | فرمان همراه فعال؛ نگه‌داشتن = تعویض همراه |
| سه دکمهٔ ابزار | ابزار فوری (Metro) |

### ۱.۲ جان
- بازیکن: ۳ قلب (تا ۸). ضربه ۱ قلب؛ ۱٫۶ث بی‌آسیبی (موجود).
- شکست در مرحله: برگشت به آخرین پرچم؛ بی‌قلب‌شدن کل: ۱ قلب انرژی کم می‌شود (نه از دست رفتن پیشرفت).
- دشمن «آزاد می‌شود»، نه کشته: افکت آزادی (ذره‌های رنگی)، سکه.

### ۱.۳ فرمول
`ضربه = base_weapon × tier_mult × element_mult × (crit?1.5:1) × (hero_atk/3)`

| سطح | mult |
|---|---|
| ۱ | ۱٫۰ |
| ۲ | ۱٫۲۵ |
| ۳ | ۱٫۵ |
| ۴ | ۲٫۰ |
| ۵ | ۲٫۵ |

عنصر: قوی ×۱٫۵؛ ضعیف ×۰٫۷۵. اگر `weapon_tier < armor_level` پاسدار: ×۰٫۰۵.
«سقف رقابت» آنلاین: tier ≤ ۳ و بدون مود پولی.

### ۱.۴ دشمن‌ها
- ۲۴ دشمن موجود + پوست هر فصل؛ رفتار: راه، پرواز، غلت، آماده‌باش، گیج.
- دشمن‌های جدید برای فصل‌های ۶–۱۵ (جدول [04 §۵](04_art_and_sound_bible.md)).
- **پاسدار** و **نگهبان** در [02_godot_spec §۵ و ۶](02_godot_spec.md).

### ۱.۵ توان ویژه و فرمان
- شارژ توان: با ضربه (۵٪) و ذره (۲٪)؛ وقتی پر شد دکمه می‌درخشد.
- فرمان همراه: وقفه ۳۰ث پایه؛ هم‌افزایی ۱۵٪ سریع‌تر.

## ۲. هاب: «دهکدهٔ برج»

صفحهٔ اصلی بازی. هر قلبی که برگردد، رنگ به دهکده برمی‌گردد.

| ساختمان | کار | باز می‌شود |
|---|---|---|
| **برج زمان** | کوک روزانه، ساعت بزرگ (پیشرفت قلب‌ها) | از اول |
| **دروازهٔ نقشه** | نقشهٔ فصل‌ها | از اول |
| **کارگاه بابابزرگ** | ارتقا و مود سلاح | بعد از فصل ۹ (نسخهٔ ساده از فصل ۱) |
| **کارگاه آتش آذر** | سطح ۵ | فصل ۱۲ |
| **لانه** | تخم‌ها، تیم همراه، کاستوم | بعد از فصل ۱ |
| **فروشگاه** | کالاها | از اول |
| **سالن قهرمان‌ها** | انتخاب و باز کردن قهرمان | بعد از فصل ۲ |
| **کتابخانه** | دفتر خاطره، دفتر شناخت پاسدار | بعد از فصل ۱۰ (کوچک از فصل ۱) |
| **میدان رقیب‌ها** | رتبه، مسابقهٔ روح، دوئل | بعد از فصل ۲ |
| **درِ میان‌زمان** | رویداد زنده | بعد از فصل ۵ (v2.5) |
| **خانهٔ مادربزرگ** | دانهٔ سبزدره؛ داستان جانبی | بعد از فصل ۸ |

- اکتشاف هاب: نقشهٔ کوچک قابل‌راه‌رفتن (جزئیات صفحه از طرح صاحب پروژه می‌آید؛ [17](17_ui_screens_design.md)).
- هاب «زنده» است: ([13](13_camera_and_living_world.md)).
