# فهرست کامل صدا

> وضعیت: پیش‌نویس ۱. قواعد صدا در [04_art_and_sound_bible.md](04_art_and_sound_bible.md) بخش ۶. جمله‌های قهرمان/همراه/دیالوگ در [content/04](content/04_heroes.md)، [05](content/05_companions.md)، [dialogue/](dialogue/README.md).
> ابزار: جلوه‌ها `tools/audio.py`؛ محیط `tools/audio/fetch_ambience.py` (Commons، منبع و مجوز در `docs/audio/sound_sources.json`) یا `synth_ambience.py`؛ صدای شخصیت: `tools/voice-studio` (آواشو). **صدا بدون نام قهرمان.** ضبط انسانی بازنویسی نمی‌شود.
> کلید فایل: `sfx_<دسته>_<نام>`، `amb_<فصل>_<زمان>`، `mus_<نام>`، `vo_<شخصیت>_<کلید>`.

## ۱. قواعد

| قاعده | مقدار |
|---|---|
| **باس‌ها** | ۴ باس: موسیقی، جلوه، محیط، صدا (voice)؛ ولوم جدا در تنظیمات |
| **اولویت** | صدا (VO) ← جلوه‌های مهم ← جلوه ← محیط ← موسیقی (داکینگ ۶ دسیبل) |
| **حداکثر هم‌زمان** | ۱۶ جلوه |
| **دو زمان** | هر فصل آمبینس + موسیقی در **نسخهٔ گذشته** (نرم، آکوستیک، گرم) و **حال** (خسته، خشک‌تر)؛ هنگام لنز **کراس‌فید ۰٫۳ث** + «ویژ» + زنگ ساعت |
| **شبح** | لایهٔ غایب صدای خیلی کم (۱۰٪) با فیلتر پایین‌گذر؛ نشانه |
| **کودک** | بدون صدای ناگهانی بلند؛ اوج ≤ −۶ dBFS؛ «حالت آرام» برای لرزش/صدا |
| **زبان** | فارسی؛ جلوه‌ها بی‌کلام |

## ۳. جلوه‌ها

### ۳.۱. حرکت

### ۳.۲. زمان

### ۳.۳. جنگ

### ۳.۴. سلاح (کار تیم صدا)

### ۳.۵. ابزار
۱۲ ابزار × استفاده/تمام شدن: `sfx_tool_<نام>_use` · `_empty`.

### ۳.۶. همراه

### ۳.۷. پاسدارها (۱۲ نوع)
