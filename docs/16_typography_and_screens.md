# تایپوگرافی و ظاهر متن

> برگهٔ نمونه: [16_font_candidates.png](16_font_candidates.png) (فقط فونت‌هایی که روی این ماشین بود؛ نامزدهای دیگر باید دانلود و رندر شوند).

## ۱. فونت‌ها (همه باید OFL یا آزاد برای بازی تجاری باشند؛ مجوز کنار فایل‌ها)

| نقش | فونت | وضعیت |
|---|---|---|
| متن عمومی و رابط | **Vazirmatn Bold** | **موجود** در `assets/fonts/` (مجوز OFL.txt) |
| عنوان‌ها و ربان‌ها | **Vazirmatn Black** | موجود |
| عنوان تزئینی (اختیاری) | Lalezar یا Estedad Black | **نامزد؛ هنوز دانلود/ارزیابی نشده** |
| روایت/کارت فصل (اختیاری) | Aref Ruqaa | نامزد؛ ارزیابی نشده |
| اعداد | ارقام فارسی از همان فونت | — |

**تصمیم موقت:** Vazirmatn (Bold + Black) برای همه‌جا؛ فونت تزئینی فقط با تأیید صاحب پروژه بعد از دیدن نمونه.

## ۲. قواعد

- راست‌به‌چپ؛ اعداد فارسی در رابط (سکه، قلب…).
- حداقل اندازه روی گوشی: ۲۲px متن، ۲۸px عنوان (در ۱۲۸۰×۷۲۰).
- متن روی پنل روشن: تیره `#5A3A1E`؛ روی تیره: سفید با خط دور ۲–۳px.
- هیچ متن داخل تصویر؛ همهٔ متن‌ها از `strings_fa.json`.
- اعراب‌گذاری جملهٔ صوتی فقط برای TTS (موجود)، نه نمایش.

## ۳. رنگ و سایه (از پالت [04 §۲](04_art_and_sound_bible.md))

| مورد | مقدار |
|---|---|
| متن اصلی | `#5A3A1E` روی پنل روشن |
| متن روی دکمهٔ سبز/نارنجی | سفید + خط دور تیره‌تر از رنگ دکمه |
| سایهٔ متن | ۲px پایین، آلفا ۰٫۳ |
| رنگ سکه / الماس / قلب | طلایی `#F6C445` / فیروزه‌ای `#2CC7E8` / قرمز `#E5484D` |
