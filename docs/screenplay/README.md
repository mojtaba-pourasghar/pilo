## قواعد فیلم‌نامه
1. هر صحنه گذشته و حال را با هم نشان می‌دهد.
2. گفت‌وگوها کوتاه (حداکثر ۲ خط در هر نمایش)، مناسب ۸ تا ۱۵ سال.
3. صداگذاری نام قهرمان را نمی‌گوید؛ زیرنویس نام انتخابی را می‌گذارد.
4. هیچ مرگ و خشونت واقعی.
5. تغییر داستان فقط با ثبت در `DECISIONS.md`.
