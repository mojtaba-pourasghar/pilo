# استودیوی صداگذاری «سفر پیلو»

همان استودیوی پروژهٔ پوپو (pokpok)، برای این بازی آماده شده. ابزاری محلی برای دو کار:

1. **صدای شخصیت‌ها:** ساخت صدای موقت جمله‌های نیما، پیلو، غبارک و سنجابک با سرویس TTS «آواشو»، هر شخصیت
   با صدا و سرعت خودش، تا وقتی گوینده‌های واقعی جمله‌ها را ضبط کنند.
2. **صداهای بازی و محیط:** جایگزین کردن جلوه‌ها، صدای محیط یا موسیقی با فایل واقعی‌ای که خودتان پیدا یا ضبط
   کرده‌اید.

همه‌چیز **مستقیم داخل خود پروژه** نوشته می‌شود و با خروجی بعدی Godot داخل بازی می‌رود. هیچ صدایی جایی آپلود
نمی‌شود و هیچ چیزی خودکار کامیت یا پوش نمی‌شود.

## اجرا

نیازها:

- **Node.js 18 یا بالاتر:** <https://nodejs.org> (نسخهٔ LTS)
- **ffmpeg** روی PATH. روی ویندوز در PowerShell بزنید `winget install Gyan.FFmpeg`، بعد PowerShell را ببندید و
  دوباره باز کنید. برای بررسی: `ffmpeg -version`

### ویندوز

روی `tools\voice-studio\start.bat` دوبار کلیک کنید. بار اول بسته‌ها را نصب می‌کند و حدود ۱۵ ثانیه بعد مرورگر
روی <http://127.0.0.1:5174> باز می‌شود. برای بستن، پنجرهٔ سیاه را ببندید.

### لینوکس / مک

```bash
cd tools/voice-studio
npm install      # فقط بار اول
npm start
```

## به کجا وصل است

| چه | کجا |
|---|---|
| متن جمله‌ها | `data/voice/voice_lines.json` (ساخته‌شده از فایل مرحله‌ها با `tools/voice/build_voice_lines.py`) |
| خروجی صدای شخصیت‌ها | `assets/audio/voice/<id>.mp3` (مثلاً `l03_intro_1.mp3`؛ بازی همین را پخش می‌کند) |
| فهرست صداهای ماشینی (موقت) | `docs/voice/tts_generated.json` |
| صداهای بازی | `assets/audio/sfx`، `assets/audio/ambient`، `assets/audio/music` (Ogg) |
| منبع و مجوز صداهای واقعی | `docs/audio/sound_sources.json` |
| تلفظ ویژه | فیلد اختیاری `spoken` در `voice_lines.json`؛ فقط استودیو آن را می‌خواند و با ساخت دوبارهٔ فهرست هم می‌ماند |
| صداهای آزمایشی | `tools/voice-studio/samples/` (بیرون از بازی و بیرون از گیت) |

## جمله‌ها از کجا می‌آیند

دیالوگ‌ها در خود فایل مرحله‌ها نوشته می‌شوند (`data/levels/<دنیا>/level_XX.json`، بخش‌های `intro`، `outro`،
`rescue` و متن تابلوها در `signs`). هر بار که دیالوگی اضافه یا عوض شد:

```bash
python3 tools/voice/build_voice_lines.py      # data/voice/voice_lines.json را به‌روز می‌کند
python3 tools/voice/make_recording_script.py  # فیلم‌نامهٔ ضبط برای گوینده‌ها
```

هر جمله یک شناسهٔ ثابت می‌گیرد (`l03_intro_2`، `l03_sign_1`، `app_unsafe`…) که همان نام فایل صداست. متن تابلوها
و پیام‌های کوتاه بازی («اینجا جای امن نیست!»، «آفرین!») را پیلو می‌خواند تا بچه‌هایی که هنوز خواندن بلد
نیستند هم بفهمند.

## تب «استودیو»: صدای شخصیت‌ها

1. **توکن** آواشو را در کادر «توکن آواشو» بچسبانید و «ذخیرهٔ تنظیمات» را بزنید. توکن در
   `voice-studio.config.json` همین پوشه ذخیره می‌شود و در گیت نیست.
2. در کارت **«صدای شخصیت‌ها»** برای هر شخصیت صدا و سرعت را انتخاب کنید و «تست با یک جملهٔ خودش» را بزنید.
   پیش‌فرض‌ها:

   | شخصیت | صدا | سرعت | چرا |
   |---|---|---|---|
   | نیما | بهار (bahar) | ۱ | آواشو صدای کودک ندارد؛ مثل دوبلهٔ کارتون‌ها پسربچه با صدای جوان زنانه |
   | پیلو | پونه (pune) | ۰٫۹ | گرم و آرام، برای راهنمایی کودک ۵ ساله |
   | غبارک | آریا (ariya) | ۱٫۱ | شیطون و تند، ولی ترسناک نه |
   | سنجابک | شیدا (sheyda) | ۱٫۱ | زیر و هیجان‌زده |

3. در تب «تست وب‌سرویس»، «نمونهٔ همهٔ گوینده‌ها» یا «نمونهٔ سرعت‌ها» را بزنید، شخصیت را از فهرست «همین برای
   کدام شخصیت؟» انتخاب کنید و کنار صدای دلخواه «همین» را بزنید.
4. «ساخت همهٔ باقی‌مانده‌ها» را بزنید، یا با فیلترها فقط یک شخصیت یا یک مرحله را بسازید.

اگر واژه‌ای بد خوانده شد، «متن» را بزنید و تلفظ را با اعراب بنویسید. این تلفظ در `spoken` ذخیره می‌شود و متنی
که بازی نشان می‌دهد عوض نمی‌شود.

**صدای ماشینی و ضبط انسانی کنار هم:** استودیو هرگز فایلی را که در `tts_generated.json` نیست بازنویسی یا پاک
نمی‌کند، پس ضبط گوینده‌ی واقعی همیشه امن است. وقتی ضبط‌ها رسید:
`tools/voice/import_recordings.sh <پوشهٔ فایل‌ها>`

## تب «صداهای بازی و محیط»

همهٔ فایل‌های `assets/audio/sfx`، `ambient` و `music` اینجا فهرست می‌شوند.

1. صدا را پیدا کنید: Freesound با فیلتر مجوز CC0، Pixabay Sound Effects، BigSoundBank، Wikimedia Commons یا ضبط
   خودتان با گوشی.
2. فایل را روی ردیف همان صدا بکشید و رها کنید، یا «انتخاب فایل» را بزنید (mp3، wav، ogg، m4a و حتی mp4).
3. استودیو با ffmpeg سکوت اول و آخر را می‌بُرد، طول را به «حداکثر طول» می‌رساند (برای صدای محیط بیشتر بگذارید)،
   فایل را مونو و هم‌بلندی (−14 LUFS) می‌کند و **روی همان فایل Ogg داخل پروژه** می‌نویسد.
4. «منبع» و «مجوز» را بنویسید؛ در `docs/audio/sound_sources.json` می‌ماند و برای انتشار در بازار لازم است.

صدای قبلی در گیت هست. اگر جایگزینی خوب نبود: `git checkout -- assets/audio/sfx/step.ogg`

## پس از ساخت صدا

پروژه را در Godot باز کنید (صداهای تازه خودکار وارد می‌شوند) و بازی را اجرا کنید. بعد:

```bash
git add assets/audio data/voice docs
git commit -m "صداهای تازه"
git push
```

## آزمایش بدون توکن

`AVASHO_HOST` آدرس سرویس را عوض می‌کند تا بشود با یک سرور ساختگی محلی آزمایش کرد:

```bash
AVASHO_HOST=http://127.0.0.1:9911 npm run server
```
