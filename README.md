# سفر پیلو

پلتفرمر معمایی دوبعدی برای کودکان ۵ تا ۹ سال، ساخته‌شده با **Godot 4.3** و **GDScript**.

در سرزمین خیالی «رنگارستان»، غبارکِ بازیگوش تکه‌های زمان را پخش کرده است. نیما به کمک همراهش پیلو و با **لنز زمان** بین «گذشته» و «حال» جابه‌جا می‌شود تا راه را پیدا کند: پلی که در گذشته سالم بوده، جوانه‌ای که در حال به گیاه تبدیل شده، سنگی که امروز دیگر نیست و آبی که روزگاری جای دیگری جاری بوده.

> گزارش کامل همهٔ کارهای انجام‌شده و وضعیت به‌روز: [`docs/WORK_LOG.md`](docs/WORK_LOG.md)

## طراحی منوها

منوها (صفحهٔ اصلی، انتخاب جهان، مکث، فروشگاه و HUD) عیناً از روی طرح `assets/reference/ui_menus_design.webp` ساخته شده‌اند. دکمه‌ها و پنل‌ها تصاویر شیشه‌ای nine-patch هستند که با `python3 tools/ui_art.py .` دوباره ساخته می‌شوند. قانون کار روی پروژه در `CLAUDE.md` آمده است: هر طرحی که صاحب پروژه می‌دهد، عین همان پیاده می‌شود.

## اجرا

1. [Godot 4.3](https://godotengine.org/download) را نصب کنید (نسخهٔ استاندارد، نه .NET).
2. پوشهٔ پروژه را در Godot باز کنید و F5 را بزنید.

## قواعد لنز زمان (پیاده‌شده)

1. فقط دو وضعیت وجود دارد: گذشته و حال.
2. هر شیء زمانی دقیقاً مشخص می‌کند در کدام زمان وجود دارد؛ نسخهٔ غایبِ آن به‌صورت «سایهٔ نقطه‌چین» دیده می‌شود تا کودک بتواند مقایسه کند.
3. اگر قهرمان در زمان مقصد داخل سنگ یا آب قرار بگیرد، تغییر انجام **نمی‌شود**: مانع قرمز چشمک می‌زند، پیلو سر تکان می‌دهد و پیام «اینجا جای امن نیست!» نشان داده می‌شود (`TimeShift.find_blocker`).
4. لنز مصرف‌شدنی نیست و به خرید یا تبلیغ نیاز ندارد.
5. افتادن یا رفتن در آب فقط قهرمان را به آخرین پرچم برمی‌گرداند؛ جان یا زمان محدود وجود ندارد.
6. هر مکانیک اول در یک موقعیت امن آموزش داده می‌شود (مرحلهٔ ۳ پل، ۴ گیاه، ۵ کلید، ۷ آب، ۸ سکوی متحرک، ۹ نجات دوست، ۱۰ ترکیب همه).

## راهنما (HintSystem)

با زدن دکمهٔ لامپ، پیلو به سمت نزدیک‌ترین سرنخِ جلوی قهرمان پرواز می‌کند. در حالت «راهنمایی بیشتر» اشیای زمانیِ اطراف آن سرنخ هم چشمک می‌زنند. بعد از چند خطا (۲ بار در «بیشتر»، ۴ بار در «کمتر») دکمهٔ لامپ خودش تپش می‌گیرد. پیلو جواب را مستقیم نمی‌گوید.

## ساخت مرحلهٔ تازه

هر مرحله یک فایل JSON است؛ منطق معماها داده‌محور است و برای هر مرحله کد جدا لازم نیست.

```json
{
  "id": 3, "world": "forest", "title": "پل دو زمانه", "goal": "تغییر وضعیت پل",
  "lens": true, "start_time": "present", "move_range": 4,
  "intro": [{"who": "pilo", "text": "..."}],
  "outro": [], "rescue": [], "signs": ["متن تابلوی اول", "..."],
  "wind_time": "both", "source_dirs": ["right"], "chase": false, "friend": "squirrel",
  "map": ["....", "..P..i....", "##########"]
}
```

هر خانهٔ نقشه ۶۴ پیکسل است. راهنمای کاراکترها:

| نماد | معنی | گذشته | حال |
|---|---|---|---|
| `#` | زمین | ✔ | ✔ |
| `o` | تختهٔ یک‌طرفه | ✔ | ✔ |
| `B` | پل | ✔ | شکسته |
| `V` | گیاه/پیچک (سکو) | جوانه | ✔ |
| `r` | سنگ بزرگ | ✔ | خرده‌سنگ |
| `~` | آب (خطر) | خشک | ✔ |
| `w` | آب (خطر) | ✔ | خشک |
| `a` | آب همیشگی | ✔ | ✔ |
| `M` | قارچ فنری | ✔ | ✔ |
| `m` / `u` | سکوی متحرک افقی / عمودی (`move_range` خانه) | ✔ | ✔ |
| `K` / `D` | کلید / درِ گردویی (ستون D = یک در) | | |
| `*` | ستاره (اختیاری، ۳ تا در هر مرحله) | | |
| `C` | پرچم (باید روی `#` باشد) | | |
| `P` / `E` | شروع / تکهٔ زمان (پایان) | | |
| `R` | دوستِ گرفتار؛ تا نجات پیدا نکند پایان قفل است | | |
| `i` | تابلو؛ متن‌ها به ترتیب از `signs` | | |
| `?` | نقطهٔ راهنمای پیلو | | |
| `G` | غبارک (فرار می‌کند) | | |
| `f` | گل تزئینی (در حال شکوفه) | | |
| `>` `<` | باد افقی؛ فقط در هوا هل می‌دهد (هیچ‌وقت کسی را از لبه نمی‌اندازد) | `wind_time` | `wind_time` |
| `^` | جریان رو به بالا؛ قهرمان را در ستون بالا می‌برد | `wind_time` | `wind_time` |
| `L` | آسیاب/کلید (با لمس روشن می‌شود و روشن می‌ماند) | ✔ | ✔ |
| `g` | دروازه؛ وقتی همهٔ `L`ها روشن و همهٔ `O`ها نورانی شوند باز می‌شود و باز می‌ماند | ✔ | ✔ |
| `S` | منبع نور؛ جهتش به ترتیب خواندن از `source_dirs` (right/left/up/down) | ✔ | ✔ |
| `/` `\` | آینه؛ با لمس به قطر دیگر می‌چرخد | ✔ | ✔ |
| `O` | چشم بلوری (حسگر نور) | ✔ | ✔ |
| `x` | بلور؛ فقط وقتی نور به آن می‌رسد سکو است | ✔ | ✔ |
| `z` | سکوی سنگی؛ در گذشته محکم، در حال ترک‌خورده (می‌لرزد، می‌ریزد و کمی بعد برمی‌گردد) | محکم | ناپایدار |

مراحل سکوبازی (`"format": 2`) این نمادها را هم دارند. فضای خالیِ زیر زمین خودبه‌خود «اتاق مخفی» می‌شود (تا نیما وارد نشود خاک دیده می‌شود):

| نماد | معنی |
|---|---|
| `Q` / `U` / `J` / `H` | جعبهٔ سؤالی: سکه / چند سکه / الماس / قلب |
| `b` / `$` | آجر (خالی می‌شکند) / آجرِ پر از سکه |
| `n` | جعبهٔ پنهان (الماس)؛ با ضربه از زیر ظاهر می‌شود |
| `c` / `d` / `+` / `k` | سکه / الماس / قلب / کلید زمان (دروازه را باز می‌کند) |
| `e` / `y` / `h` | قارچ‌سایه / زنبور سایه (`bee_span`) / خارپشت سایه (فقط با پیلو) |
| `A` | خار |
| `F` | چرخ خار (`wheel_length`) |
| `T` | سنگ‌کوب |
| `t` | قایق ریزان (دو خانه) |
| `N` | توپ سایه |
| `W` | دیوار ترک‌دار (ستونی)؛ با دَش یا پیلو می‌شکند |
| `p` | لوله (گوشهٔ بالا-چپ، دو خانه پهنا)؛ مقصد در `warps`: `{"from": [x, y], "to": [x, y]}` |

مرحلهٔ ۱ با `python3 tools/levels/forest_01.py` ساخته می‌شود (نقشه از قطعه‌های نام‌دار، خواناتر از نوشتن دستی).
بقیهٔ ۷۱ مرحله با `python3 tools/levels/compose.py` از قطعه‌های طراحی‌شده چیده می‌شوند (۴۶ نوع قطعه؛ هر جهان دو قطعهٔ
ویژهٔ خودش را دارد: کلاهک قارچ‌ها و تپهٔ توخالی، تالاب مرجانی و کشتی شکسته، هرم و شن‌های روان، غار یخی و نردبان کاج،
پله‌های ابری و جزیره‌پرانی، معدن بلور و ستون تاریک، برج تسمه و تالار پرس، دیوار قلعه و تالار خار، پیچ‌وخم وارونه و پله‌های آینه‌ای).
مرحله‌های ۱ تا ۳ هر جهان طراحی‌شده‌اند (`tools/levels/authored.py`: قطعه‌ها و ترتیبشان، جای راه بالا و تونل زیرزمین و گفت‌وگو).
**حداقل مسیرها:** هر مرحلهٔ عادی راه بالایی (دست‌کم ۴۰٪ طول مرحله)، راه زیرزمینی و یک لوله یا لانهٔ مخفی دارد؛
`python3 tools/levels/routes.py` این‌ها را روی جست‌وجوی دسترسی‌پذیری اندازه می‌گیرد و `compose.py` رعایتش را اجبار می‌کند.

نور با `#`، فنر، در و دروازهٔ بسته، و سنگ `r` **فقط در گذشته** متوقف می‌شود؛ پس لنز زمان مسیر نور را هم عوض
می‌کند. در هر دنیا همان کاشی‌ها ظاهر خودشان را دارند: در جزیره‌ها `r` ابر طوفانی، `V` ابر و `B` پل نور است؛
در غارها `r` خوشهٔ بلور و `V` لبهٔ بلوری.

گزینه‌های مرحله: `wind_time` (باد در کدام زمان: `past`/`present`/`both`)، `source_dirs`، `chase: true`
(غبارک جلو می‌دود و کنار در منتظر می‌ماند تا گرفته شود)، `friend` (`squirrel`، `cloud` یا `ghubarak`).

مرحله‌های هر دنیا در `data/levels/<جهان>/level_XX.json` هستند (forest، coral_beach، golden_desert، snow_mountain، sky_islands، crystal_caves، clock_factory، shadow_castle، inverted_land).

## تصویرهای بازی (شخصیت‌ها و محیط‌ها)

همهٔ شخصیت‌ها و محیط‌ها تصویر سه‌بعدیِ رندرشده‌اند (نه نقاشی)، ساختهٔ Cloudflare Workers AI (FLUX)؛
نسخه‌های کدیِ قبلی فقط وقتی تصویری نباشد جایگزین می‌شوند.

- فهرست تصویرها و متن درخواست هر کدام: `tools/art/manifest.json` (سبک‌ها در `styles`).
- ساخت: `CF_KEYS="account:token,..." python3 tools/art/cf_generate.py` (تصویر ساخته‌شده دوباره ساخته نمی‌شود؛
  وقتی سهمیهٔ روزانهٔ یک حساب تمام شود سراغ حساب بعدی می‌رود). خروجی خام در `art_src/`.
- پردازش: `venv/bin/python tools/art/postprocess.py` (برش پس‌زمینه با rembg، بافت‌های بی‌درز، کوچک‌کردن) → `assets/art/`.
- **حالت‌ها به‌جای برش:** هر شخصیت برای هر حرکت تصویر جدای خودش را دارد و پشت سر هم پخش می‌شوند (مثل کارتون):
  - نیما و پیلو (`PaintedRig`): `<نام>_run_a..d`، `_walk_a/b`، `_idle_b` و حالت‌های پرش، سُر خوردن، ضربه، جشن و خستگی.
  - دشمن‌ها، غول‌ها و همراه‌ها (`PaintedCreature`): `walk_a/b/c`، `fly_a/b/c`، `roll_a/b`، `hurt`، `windup`، `stunned`.
    نسخهٔ «سایه‌گرفته» با شیدر `shadow_tint` تیره می‌شود و با آزاد شدن رنگ واقعی برمی‌گردد.
  - پیش‌نمایش: `godot --path . res://tools/rig_preview.tscn -- --painted` و `res://tools/creature_preview.tscn -- --big`.
- برش اعضا (`tools/art/rigs.json`، `tools/art/make_rig.py`) فقط وقتی حالت‌های کشیده‌شده نباشند جایگزین می‌شود.
- ساخت دوبارهٔ تصویرهای انتخابی: `tools/art/redo.sh <id...>` (تصویر قدیمی تا ساخته شدن تصویر جدید می‌ماند).
- تصویر گفت‌وگو: چهرهٔ گوینده در قاب گرد؛ اگر تصویری نباشد حرف اول اسم.
- محیط هر جهان (`WorldArt`): `<جهان>_far` (چشم‌انداز دور)، `tree_1..3` و `bush_1..3` (دو ردیف پس‌زمینه)،
  `soil`، `turf` و `wood` (بافت زمین، لبهٔ چمن/شن/برف و سکوها)؛ جعبه‌ها، دروازهٔ زمان، لوله، دیوار ترک‌خورده و خارها.
- کلیدها هرگز در مخزن ذخیره نمی‌شوند.

## خروجی اندروید

1. در Godot از مسیر *Editor → Manage Export Templates* قالب‌های 4.3 را نصب کنید.
2. در *Editor Settings → Export → Android* مسیر Android SDK و JDK 17 را بدهید ([راهنمای رسمی](https://docs.godotengine.org/en/4.3/tutorials/export/exporting_for_android.html)).
3. *Project → Export → Android* (پیش‌تنظیم آماده است، شناسهٔ بسته `ir.safarpilo.game` را در صورت نیاز عوض کنید).
4. برای نسخهٔ انتشار، کلید امضا بسازید و آن را **فقط** در `export_credentials.cfg` محلی نگه دارید (این فایل و `*.keystore` در `.gitignore` هستند).

## فروشگاه و خرید درون‌برنامه‌ای

- بازی فقط از `StoreAdapter.purchase()`، `restore()` و `owns()` استفاده می‌کند.
- در نسخهٔ Debug یک پیاده‌سازی آزمایشی خرید را فوراً تأیید می‌کند؛ در نسخهٔ Release تا وقتی SDK رسمی وصل نشود هیچ خریدی انجام نمی‌شود.
- قبل از هر خرید، دروازهٔ والدین (ضرب دو عدد دورقمی با صفحه‌کلید) نمایش داده می‌شود.
- قیمت‌ها هنوز تعیین نشده‌اند («قیمت: به‌زودی»).
- دنیاهای ۲ تا ۸ با «بستهٔ دنیاهای ۲ تا ۸» باز می‌شوند. زدن روی دنیای قفل در صفحهٔ انتخاب جهان، فروشگاه را باز می‌کند.
  در نسخهٔ Debug (اجرا از داخل Godot) خرید آزمایشی بعد از دروازهٔ والدین فوراً انجام می‌شود. در نسخهٔ Release تا
  وقتی پرداخت کافه‌بازار/مایکت وصل نشود، این بسته فروخته نمی‌شود.
- پیلوی طلایی خریدنی نیست؛ جایزهٔ تمام‌کردن مرحلهٔ ۶۴ (نگهبان دنیای ۸) است.
- **دهکدهٔ پیلو** (دکمهٔ «دهکده» در صفحهٔ انتخاب جهان، `scripts/ui/village.gd`): ۱۲ همراه و ۱۲ ابزار
  (`scripts/economy/loadout.gd`). هفت همراه با آزاد کردن نگهبان هر جهان رایگان می‌آیند، بقیه با سکه/الماس
  جمع‌شده در مرحله‌ها؛ اژدهاک، شیرک بالدار، اسکیت موشکی، بالن رنگین‌کمان و جعبه‌ابزار طلایی با پول واقعی
  (پشت دروازهٔ والدین). یک همراه و دو جای ابزار (سه با جعبه‌ابزار). راه اصلی هیچ مرحله‌ای به خرید نیاز ندارد؛
  سکه و الماس هرگز با پول فروخته نمی‌شوند. فقط همراه انتخاب‌شده (با تصویر و حالت‌های خودش) در مرحله دنبال نیما می‌آید و هر کدام در مراحل «جای مخصوص»
  خودش را دارد. ۵ سلاح (تیرکمان رایگان، تفنگ حبابی، بومرنگ، عصای آتش، ستاره‌پران با پول واقعی) هم در دهکده‌اند.
  وسط مرحله، دکمهٔ کوله بازی را نگه می‌دارد و همراه، ابزارها و سلاح عوض می‌شوند (`scripts/ui/team_picker.gd`).
- برای اتصال واقعی، افزونهٔ رسمی پرداخت کافه‌بازار (Poolakey) یا مایکت را به‌صورت Android plugin اضافه کنید و فقط داخل `scripts/economy/store_adapter.gd` صدا بزنید؛ تأیید تراکنش ترجیحاً سمت سرور انجام شود.

## صدا

بازی چهار کانال جدا دارد که هرکدام در تنظیمات اسلایدر خودش را دارد: **موسیقی**، **جلوه‌ها**، **صدای محیط** و
**گوینده**. وقتی شخصیتی حرف می‌زند موسیقی کمی پایین می‌آید.

**صدای محیط**
- هر دنیا صدای محیط حلقه‌ای و بی‌درز خودش را دارد:
  - **جنگل:** نسیم و آواز پرنده‌ها، ضبط واقعی از Wikimedia Commons (مالکیت عمومی).
  - **جزیره‌های ابری:** باد کوهستان با وزش‌های آرام و زنگوله‌های بادی دور.
  - **غارها:** وزوز آرام غار و چکه‌های آب با پژواک بلند.
  - **جریان آب** آبراه‌ها: بستر آب با حباب‌های کوچک.
  - **ساحل:** موج؛ **بیابان:** باد داغ؛ **کارخانه:** تیک‌تاک و ماشین‌ها؛ **قلعه:** شب؛ و **باران** در مراحل بارانی.

  این‌ها (به‌جز جنگل) با کد ساخته شده‌اند (`python3 tools/audio/synth_ambience.py`). ضبط واقعی با
  `python3 tools/audio/fetch_ambience.py` از Commons گرفته می‌شود (انتخاب‌ها در `tools/audio/picks.json`،
  منبع و مجوز در `docs/audio/sound_sources.json`). برای این سه مورد هم انتخاب آماده است، ولی Commons هنگام ساخت
  دانلودها را محدود کرد. هر وقت اجرا شود، ضبط واقعی جای نسخهٔ ساخته‌شده می‌نشیند.
- آبراه‌ها صدای جریان آب دارند که از خودِ آب پخش می‌شود (هرچه نزدیک‌تر، بلندتر) و با تغییر زمان، همراه آب
  محو یا ظاهر می‌شود.
- **لنز زمان شنیده هم می‌شود:** در «گذشته» صدای محیط گرفته و دور می‌شود، مثل یک خاطره. گیاه‌ها هنگام رشد خش‌خش
  می‌کنند، سنگ‌ها غرّش می‌کنند و پل جیرجیر می‌کند.
- صدای قدم روی چمن، خندهٔ غبارک، جیک‌جیک سنجابک، ترکیدن حباب، پرچم، ضربه، ووش، آتش، رعد، نفس‌نفس و جِزجِز با کد
  ساخته شده‌اند (`tools/audio.py`). ضربه‌ها با لرزش تصویر و لرزش گوشی همراه‌اند (در تنظیمات خاموش می‌شود).

**صدای شخصیت‌ها**
- همهٔ جمله‌ها (دیالوگ مرحله‌ها، متن تابلوها که پیلو بلند می‌خواند، و پیام‌های کوتاه مثل «اینجا جای امن نیست!»)
  در `data/voice/voice_lines.json` هستند و هرکدام نام فایل ثابت دارند.
- **استودیوی صداگذاری** (`tools/voice-studio`، همان استودیوی پروژهٔ پوپو) با سرویس آواشو برای هر شخصیت با صدای
  خودش صدای موقت می‌سازد. راهنما: [tools/voice-studio/README.md](tools/voice-studio/README.md). ویندوز:
  دوبار کلیک روی `tools\voice-studio\start.bat`.
- ضبط گوینده‌های واقعی با `tools/voice/import_recordings.sh` وارد می‌شود و هرگز با صدای ماشینی جایگزین نمی‌شود.
  فیلم‌نامهٔ ضبط: `docs/voice/RECORDING_SCRIPT.md`.
- تا وقتی فایل صدایی نیست، متن در حباب نوشته می‌شود و بازی بی‌وقفه کار می‌کند.

## قدم‌های بعدی پیشنهادی

1. آزمون مراحل با کودکان گروه سنی هدف (با رضایت و نظارت والدین) و اصلاح سختی بر اساس آمار محلی.
2. تصویرهای باقی‌مانده: مادربزرگ کاکتوس، دو حالت راه رفتن قارچ، حالت‌های دویدن کیان از پهلو، طراحی دوبارهٔ خفاش.
3. ساخت صدای موقت شخصیت‌ها با استودیو، و بعد ضبط گوینده‌های واقعی از روی `docs/voice/RECORDING_SCRIPT.md`.
4. اتصال پرداخت رسمی و آزمون خرید موفق، لغوشده، خطای شبکه و بازیابی.
5. بررسی شرایط استفادهٔ تجاری تصویرهای ساخته‌شده و صدای آواشو پیش از انتشار.
