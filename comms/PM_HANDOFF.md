# اتصال مدیر پروژه — چت جدید (۲۲ نوامبر ۲۰۲۶)

## چه شد
- نقش مدیر پروژه از چت قبلی به این چت منتقل شد (تصمیم مالک). پیاده‌سازی کد به **Qwen Code** سپرده می‌شود؛ مدیر پروژه اسناد و طرح‌ها را مستقیم کامیت می‌کند.
- وضعیت مخزن راستی‌آزمایی شد: دستور ساخت جفت ۱ (`docs/CLAUDE_CODE_ORDER_PAIR1_BUILD.md`) پوش شده ولی **هنوز اجرا نشده**؛ هر ۹ برگه در `assets/art/pair1_sheets/` موجود است.

## بستهٔ ۰۰۲ (در دست ساخت توسط مدیر پروژه)
1. `docs/34_hero_micro_motion.md` — جدول ریزحرکت آرسام و پدربزرگ جوان (رفع شکاف P2)
2. طرح ۷ منوی G5: موکاپ SVG + مشخصات انیمیشن، ثبت در `docs/design_sheets/SCREEN_DESIGNS.md`
3. `comms/ART_REQUESTS.md` — پرامپت Canva برای Rootstomp، Barkshield، مو و دست‌های کمان آرسام، نوار لخت درخت
4. `docs/QWEN_CODE_ORDER.md` — همان دستور P0–P11 برای Qwen Code + گام صفر
5. اصلاح `README.md` (هنوز بازی قدیمی را توصیف می‌کند)

## سؤال باز برای مالک
- هنر منوها: موکاپ کدی دقیق + اجرای شیشه‌ای با کد (سابقهٔ `tools/ui_art.py`) یا برگهٔ Canva؟
  پیش‌فرض مدیر: مسیر کدی؛ مالک می‌تواند رد کند. تا پاسخ، طرح‌ها ساخته می‌شوند ولی منویی پیاده نمی‌شود.

## امنیت دسترسی
- دسترسی نوشتن با توکن محدودِ خودِ مالک انجام می‌شود؛ توکن در هیچ فایل/لاگ/کامیتی ذخیره نمی‌شود
  و مالک پس از پایان کار آن را باطل می‌کند (قاعدهٔ ۱۲).
