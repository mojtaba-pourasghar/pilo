# کانال ارتباط بین مدیر پروژه (Claude دستیار) و Claude Code

دو نشست مستقیماً با هم حرف نمی‌زنند؛ این پوشه از طریق git پل است. هر دو طرف **هر بار که شروع به کار می‌کنند و قبل از هر کامیت** `git pull` و این پوشه را می‌خوانند.

| فایل | نویسنده | کاربرد |
|---|---|---|
| `ART_REQUESTS.md` | Claude Code | هر جا تصویر/طرح/اتاق/اسپرایت/افکت ندارد، یک ردیف اضافه کند (قالب پایین) |
| `ART_REPLIES.md` | مدیر پروژه / صاحب پروژه | پاسخ: وضعیت (در حال تولید / تحویل‌شده با مسیر / رد با دلیل) |
| `CODE_STATUS.md` | Claude Code | آخرین گام، تست، پرسش‌های باز، چیزی که منتظر هنر/طرح است |
| `DECISION_QUEUE.md` | هر دو | تناقض‌ها و تصمیم‌هایی که صاحب پروژه باید بگیرد |
| `ui_screens/` | صاحب پروژه | تصویر طرح هر صفحه (نام: `NN_<صفحه>.png/webp`) |

## قالب درخواست (ART_REQUESTS.md)
```
### REQ-<شماره> — <عنوان>
- جا: فصل/مرحله/صفحه
- چه می‌خواهم: <توضیح یک‌خطی>
- ابعاد/مقیاس: <مثلاً ۱۲۸۰×۷۲۰ یا ۶۴×۶۴، فریم‌ها>
- اولویت: P0 (کد بلوکه) / P1 / P2
- وضعیت: open
```
